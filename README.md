# Recomendador de Jogos 

## O que tem aqui
- backend/ (Node + Express)
- frontend/ (HTML, CSS, JS)
- db.json (banco local em JSON; fácil de migrar para Postgres + Docker depois)

## Como rodar (local)
1. Backend:
   ```
   cd backend
   npm install
   npm start
   ```
   O servidor irá rodar em http://localhost:3000
